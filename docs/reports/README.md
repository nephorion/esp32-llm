# Reports

Short summaries of what was tried, what it gained and where it is in the code. One file per
report, named `YYYY-MM-DD-topic.md`, newest first. A report is a record of its date: add a new
one instead of rewriting an old one.

| Date | Report |
|---|---|
| 2026-11-27 | [MiniLM speed-ups](2026-11-27-minilm-speedups.md): from 3.54 s to 0.73 s per 16-token embedding |

Each report has: **Summary**, **Changes** (date, commit, PR), **Where in the code**,
**Findings** (what worked and what did not), **Open items** and **How to reproduce**.
